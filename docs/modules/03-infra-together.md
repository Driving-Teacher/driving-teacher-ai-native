[00 · 왜 모여서 하나]
## 각자 하면, 막힌 데서 {그냥 멈춥니다.}

> 설치는 혼자 해도 됩니다. 그런데 안 될 때가 문제예요.

- 에러 하나에 막혀서 그날 저녁을 통째로 쓰거나
- 그냥 포기하고 원래 방식으로 돌아가거나
- 물어보기 민망해서 며칠을 그대로 두거나

**그래서 이건 같이 합니다.** 옆에서 화면 보고 5초면 끝나는 것들이라서요.

[01 · 오늘 붙일 것]
## 셋을 붙입니다.

:::card 📊 Zeude
팀 AI 대시보드. 회사 스킬이 자동으로 내 컴퓨터에 들어옵니다.
:::

:::card 💬 Hermes
슬랙에서 일하는 봇. 터미널을 안 열어도 시킬 수 있습니다.
:::

:::card 🔄 계정 풀
각자 계정을 모아서 돌려 씁니다. 한 명이 한도에 걸려도 안 멈춥니다.
:::

---

[02 · Zeude]
## 스킬을 {받는} 곳이자, 팀이 뭘 하는지 {{보이는}} 곳.

- 누가 만든 회사 스킬이 다음 sync 때 내 컴퓨터로 자동으로 들어옵니다
- 팀 전체가 AI를 얼마나·어디에 쓰는지 한 화면에서 보입니다
- 내가 만든 스킬을 전사에 배포하는 것도 여기서 합니다

```
/zeude-setup
```

!! 예전엔 스킬을 KB 레포에 push 해서 공유한다고 안내했습니다. 지금은 Zeude 가 표준입니다. KB 레포에는 KB 데이터를 다루는 스킬만 둡니다.

---

[03 · Hermes]
## 터미널을 안 열어도 {슬랙에서} 시킵니다.

@ Claude Code | 정밀 수술 | 앉아서 같이 파고들 때
@ Hermes | 항상 옆의 비서 | 이동 중에, 슬랙에서 한 줄로

- 대화할수록 내 업무 패턴을 기억해서 점점 정확해집니다
- `매일 9시에 ___` 한 문장으로 반복 작업을 예약할 수 있습니다

```
/hermes-setup
```

---

[04 · 계정 풀]
## 한 명이 막히면 다 막히는 걸, {안 막히게.}

:::card 계정 하나를 같이 쓰면
그 계정이 한도에 걸리는 순간 전원이 멈춥니다.
:::

:::card 계정 여러 개를 풀에 모으면
순서대로 돌려 씁니다. 하나가 걸려도 나머지가 받습니다.
:::

> 비밀번호는 주지 않습니다. OAuth 승인만 하면 끝이고, 언제든 뺄 수 있습니다.

```
/cliproxy-connect
```
