# AI Native 세션 모듈

발표용 덱을 **주제 단위**로 쪼개둔 곳입니다. 「Week 1」처럼 순서에 묶인 이름 대신, 필요한 모듈만 골라서 그 회차를 구성합니다.

## 왜 이렇게 바뀌었나

시즌1은 4주 코스였고 덱도 `week1~4-kickoff.html` 로 묶여 있었습니다. 문제는 이름이 순서를 강제한다는 것이었어요. 하나만 고치려 해도 전체를 건드려야 하니까 아무도 안 고쳤고, 대신 덱 앞에 "이건 이제 안 씁니다" 슬라이드를 덧붙이는 식으로 넘어갔습니다. 그렇게 시즌1 내용과 실제로 하는 말이 갈라졌습니다.

실제로 시즌2가 어떻게 굴러갔는지 보면 답이 나와 있었습니다 — **주제 하나 고르고, 짧은 오프닝 만들고, 나머지는 재활용.** 그게 모듈 방식이지 4주 코스가 아닙니다.

## 도구 사용법은 여기 없습니다

개인이 혼자 익히는 것(Claude Code, `CLAUDE.md`, 스킬 만들기, MCP, 플러그인)은 전부 **`/ai-onboarding` Step 1~13** 으로 갔습니다. 이 모듈들에서 다시 가르치면 같은 내용을 두 군데서 관리하게 되고, 그게 지금 고치고 있는 문제의 원인입니다.

> **여기 남기는 것 = 모여야만 되는 것.**

## 모듈

| 모듈 | 분량 | 얼마나 자주 손보나 |
|---|---|---|
| `01-why-ai-native` — 왜 AI Native 인가 | 15분 | 거의 안 바뀜 |

| `05-retro-declare` — 회고 · 선언 | 40분 | 시즌 마지막 회 |

한 회차는 보통 `02` 하나 + 다른 모듈 하나로 짭니다.

## 고치는 법

**`.md` 만 고칩니다. `.html` 은 구운 결과물이라 직접 고치면 다음 빌드에 사라집니다.**

```bash
python3 scripts/build-deck.py            # 전체 다시 굽기
python3 scripts/build-deck.py 02-case    # 이름에 02-case 가 든 것만
python3 scripts/build-deck.py --check    # 굽지 않고 최신인지만 확인
```

덱을 열려면 `.html` 을 브라우저로 그냥 열면 됩니다. `←` `→` 또는 클릭으로 넘깁니다.

## 문법

`---` 한 줄이 장 구분입니다.

| 쓰는 법 | 나오는 것 |
|---|---|
| `[00 · 오늘 흐름]` | 좌상단 라벨 |
| `## 제목` | 슬라이드 제목 |
| `> 문장` | 큰 리드 문장 |
| `- 항목` | 목록 |
| `@ 09:30 \| 제목 \| 설명` | 타임라인 한 줄 |
| `:::card 제목` … `:::` | 카드 (연달아 쓰면 가로로 붙음) |
| `!! 문장` | 노란 강조 박스 |
| `{글자}` | 보라 강조 |
| `{{글자}}` | 노랑 강조 |
| `**글자**` | 굵게 |
| `` `글자` `` | 코드 |
