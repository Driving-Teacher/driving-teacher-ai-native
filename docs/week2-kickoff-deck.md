```

3. 한 줄 느낌 — "생각보다 ___했다"

안 한 사람도 OK:
"이런 걸 해보려 했는데 ___에서 막혔다" 면 충분합니다.
```

## Slide 7: Git 교육

**화면**: Git이 뭔지 + clone / pull / add + commit + push

### Part 1: Git이 뭔지 (3분)

**말할 것**:
- "Git이 뭐냐면 — **파일 버전 관리 도구**입니다."
- "노션이 문서를 저장하는 곳이면, Git은 코드를 저장하는 곳이에요."
- "우리 팀의 스킬, 설정, 자료를 한 곳에 모아서, 누가 뭘 바꿨는지 추적할 수 있어요."
- "여러분이 만든 스킬을 Git에 올리면 → 팀 전원이 쓸 수 있게 됩니다."

### Part 2: 명령어 (5분)

**말할 것**:
- "딱 이것만 알면 됩니다."

```
받기:     git clone [URL]           ← "다운로드" — 처음 한 번만
당기기:    git pull                  ← "최신으로 업데이트" — 자주
올리기:    git add .                 ← "이거 올릴 거야"
          git commit -m "메시지"     ← "확정"
          git push                  ← "업로드"
```

### Part 3: 부딪힐 것들 (2분)

**말할 것**:
- "몇 가지 안 될 때가 있어요:"
- **"Permission denied"** → GitHub 로그인이 안 된 거. `gh auth login` 하면 됨
- **"충돌(conflict)"** → 다른 사람이 같은 파일을 수정한 거. `git pull` 하고 다시 push
- **"push 안 됨"** → 일단 Claude한테 "git push 해줘"라고 시키면 됨
- "기억하세요 — **모르면 Claude한테 물어보세요.** Git 명령어도 Claude가 다 알아요."

### Part 4: 따라하기 (5분)

**말할 것**:
- "지금 따라해보세요."

```
1. 우리 팀 레포 받기:
   git clone https://github.com/Driving-Teacher/driving-teacher-ai-native.git

2. Knowledge Base 레포도 받기 (도메인 자료):
   git clone https://github.com/Driving-Teacher/driving-teacher-knowledge-base.git

3. 되는지 확인:
   cd driving-teacher-ai-native && ls
```

> 15분. 안 되는 사람은 승아가 바로 도와줌.
