## Slide 5: Git 최소 생존 키트

**화면**: clone / pull / add + commit + push

**말할 것**:
- "오늘 만든 스킬을 팀 레포에 올릴 겁니다. 그래서 Git을 딱 이것만 알면 됩니다."
- "받기: git clone — 다운로드"
- "당기기: git pull — 최신으로 업데이트"
- "올리기 3줄 세트: git add . → git commit -m '메시지' → git push — 업로드"
- "충돌나면? git pull 하고 다시 push."
- "이것만 알면 됩니다. 나머지는 Claude한테 물어보세요."

> 10분. 화면에 띄워놓고 따라하게.
> 레포 clone: git clone https://github.com/Driving-Teacher/driving-teacher-ai-native.git

## Slide 6: 페어 실습

**화면**: "짝지어서 회사 문제 하나를 AI로 풀기"

**말할 것**:
- "지금부터 60분입니다."
- "2명씩 짝을 지어서, 둘 중 한 사람의 업무 고민을 같이 풀어봅니다."
- "먼저 5분 — 짝끼리 각자 고민을 공유하고, 둘 중 하나를 골라요."
- "그 다음 40분 — 문제를 쪼개서 각자 컴퓨터에서 분담해서 풀기."
- "예시:"
  - "CS FAQ 정리: A는 채널톡 문의 패턴 분석, B는 기존 FAQ에서 빠진 항목 찾기"
  - "온보딩 가이드: A는 기존 문서 정리, B는 빠진 항목 신규 작성"
- "마지막 15분 — 결과를 합치고, 스킬로 만들 수 있으면 스킬로 만들어서 레포에 push."
- "결과를 **슬랙 #ai-native-camp에 공유**해주세요."

> 60분. 승아 + 멘토가 돌아다니면서 도와줌.
> "뭘 해야 할지 모르겠다"는 팀이 있으면 고민 잡아주기.
> push 막히면? "Claude한테 'git push 해줘'라고 시키거나, 파일을 슬랙에 공유도 OK."
> 짝 구성: 승아가 사전에 정해둔다 (비슷한 역할끼리 or 다른 역할끼리).
