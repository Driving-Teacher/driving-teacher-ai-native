## Slide 4: Git 최소 생존 키트

**화면**: clone / pull / add + commit + push

**말할 것**:
- "오늘 만든 스킬을 팀 레포에 올릴 겁니다. 그래서 Git을 딱 이것만 알면 됩니다."
- "받기: git clone — 다운로드"
- "당기기: git pull — 최신으로 업데이트"
- "올리기 3줄 세트: git add . → git commit -m '메시지' → git push — 업로드"
- "충돌나면? git pull 하고 다시 push."
- "이것만 알면 됩니다. 나머지는 Claude한테 물어보세요."

> 10분. 화면에 띄워놓고 따라하게.

## Slide 5: Zeude 셋업

**화면**: 측정 / 배포 / 추천

**말할 것**:
- "스킬 push하기 전에 Zeude를 먼저 셋업합니다."
- "Zeude가 뭐냐면 — 누군가 스킬을 만들어서 레포에 올리면, 팀 전원에게 자동으로 설치해주는 도구예요."
- "그리고 누가 얼마나 AI를 쓰는지 측정도 됩니다. 회고 때 쓸 거예요."
- "슬랙에 보낸 링크 눌러서 설치해주세요. 1분이면 됩니다."

> 10분. 소개 5분 + 설치 5분.
> 설치 명령어는 승아가 슬랙에 미리 공유.

## Slide 6: 페어 실습

**화면**: "짝지어서 회사 문제 하나를 AI로 풀기"

**말할 것**:
- "지금부터 50분입니다."
- "2명씩 짝을 지어서, 둘 중 한 사람의 업무 고민을 같이 풀어봅니다."
- "먼저 5분 — 짝끼리 각자 고민을 공유하고, 둘 중 하나를 골라요."
- "그 다음 35분 — 문제를 쪼개서 각자 컴퓨터에서 분담해서 풀기."
- "예시:"
  - "CS FAQ 정리: A는 채널톡 문의 패턴 분석, B는 기존 FAQ에서 빠진 항목 찾기"
  - "온보딩 가이드: A는 기존 문서 정리, B는 빠진 항목 신규 작성"
- "마지막 10분 — 결과를 합치고, 스킬로 만들 수 있으면 스킬로 만들어서 레포에 push."
- "결과를 **슬랙 #ai-native-camp에 공유**해주세요."

> 50분. 승아 + 멘토가 돌아다니면서 도와줌.
> "뭘 해야 할지 모르겠다"는 팀이 있으면 고민 잡아주기.
> push한 스킬이 Zeude로 다른 팀에게 자동 배포되는 걸 보여주기.
