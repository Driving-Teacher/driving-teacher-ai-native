05—비교

Claude Code vs Hermes

Claude Code Hermes Agent
WHERE 터미널 슬랙 DM
WHEN 내가 열었을 때 항상 켜져 있음
HOW 명령 1회성 자동 예약 (cron)
MEMORY CLAUDE.md (수동) 자동 메모리 축적
LEARNING 세션마다 리셋 쓸수록 똑똑해짐

둘 다 쓰면 좋습니다. 용도가 다를 뿐.

Claude Code = 정밀 수술 | Hermes = 항상 옆에 있는 비서

06—Hermes

쓸수록 나를 아는 AI

  • 자가학습 루프 — 대화할수록 나의 업무 패턴을 기억
  • 슬랙 봇 — 터미널 없이, 슬랙 DM으로 요청
  • 자동 예약 — cron으로 반복 작업 예약
  • 메모리 — 지난 대화를 기억하고 점점 정확해짐
쓸수록 나를 아는 AI가 됩니다

"지난번에 부탁한 그 형식으로 해줘" — 가 통합니다.
