내 Codex CLI를 풀에 연결. 이제 풀 전체 계정을 라운드로빈으로 같이 씁니다.

넣기만 하고 연결을 안 하면 — 내 Codex는 여전히 내 계정 하나만 봐요. 오늘 연결해야 비로소 "풀"이 됩니다.

01—왜 연결하나

내 계정 하나로는, 금방 막힙니다.

🧍

내 계정만 보면

한도에 닿는 순간 나는 멈춤. 남이 안 쓰고 남겨둔 여유는 나한테 안 옵니다.

👥🔄

풀에 연결하면

요청이 풀의 계정들에 round-robin으로 분산. 한 계정이 한도를 쳐도 나머지로 자동 우회됩니다.

넣은 사람이 많을수록, 연결한 모두가 더 오래 안 막히고 씁니다.

02—Codex vs Claude Code

같은 풀, 연결 방식만 다름.

🟣 Codex CLI

~/.codex/config.toml에 provider 한 블록 추가. 실행은 codex --profile rrproxy — 한 단계 더 있어요.

🟡 Claude Code

환경변수 두 줄(주소 + 토큰)이면 끝. 실행은 그냥 claude — 더 간단해요.

키도 같고 풀도 같아요. 스킬이 둘 다 자동으로 세팅해주니 방식 차이는 몰라도 됩니다. Codex 앱/IDE 확장도 같은 config를 읽어요.

03—무엇을 하나

스킬 한 번이면,
설정은 자동.

✅ 이렇게 동작

/cliproxy-connect 실행 → config.toml·환경변수를 자동 세팅(기존 백업). 키는 슬랙 DM으로 받은 sk-… 하나만.

🛟 안심 포인트

평소 내 구독은 alias·프로필로 분리해 안 건드림. 언제든 원복 가능. 키는 파일로만 저장됩니다.

⚠️ 받은 키는 회사 내부 전용 — 채팅 붙여넣기·깃허브 커밋·외부 공유 금지. (레포가 공개라 더더욱)

04—실습 — 이렇게 하면 됩니다

1인 5분. 순서만 따라오세요.

1
슬랙 DM으로 API 키 받기 (1인 1개)
진행자가 sk-… 키를 DM으로 줘요. 공개 채널 말고 DM.
2
Claude Code에서 /cliproxy-connect 실행
Codex만 / Claude만 / 둘 다 중에 골라요. 보통 codex 선택.
3
키는 터미널에 직접 붙여넣기
스킬이 안내하는 한 줄에 키를 붙여넣으면 키 파일로 저장돼요. 채팅창엔 붙여넣지 마세요.
4
스킬이 config 자동 세팅 (기존 백업)
config.toml / 환경변수를 알아서 넣어줘요. 직접 편집할 필요 없음.
5
새 터미널에서 한 줄 테스트
codex --profile rrproxy "say ok" → 응답 오면 끝! 환경변수는 새 터미널에서만 적용돼요.
