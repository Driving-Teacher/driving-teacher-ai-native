이 캠프는
교육이 아니다

  • 누가 가르쳐주는 게 아니라
  • 각자 AI와 대화하면서 발견하는 과정
  • 내가 해줄 수 있는 건 방향과 도구뿐
  • 나머지는 여러분이 직접 해야 함
AI Native란?
≠ ChatGPT를 잘 쓰는 것
≠ 기존 업무에 AI를 붙이는 것
= AI가 있다는 전제로 업무를 재설계하는 것
지금 하고 있지만,
사실 안 해도 되는 일은 뭔가?

"더 잘하는 것"이 아니라 "안 하는 것"을 찾는 캠프

설문 결과

여러분이 귀찮다고 한 것들

  • 리서치/인터뷰 자료 요약에 시간이 너무 오래 걸림
  • 채널톡에서 비슷한 패턴의 답변을 반복
  • 계약서 검토, 서류 작성, 매출 프로젝션
  • 문서 포맷이 안 정해져서 매번 처음부터
  • 데일리 스크럼 쓰기

오늘 이것들을 해결합니다.

실습 1 — Claude Code 첫 체험 (15분)
$ claude
> 이번 주 할 일을 표로 정리해줘
  • "이 데이터 분석해서 인사이트 3개 뽑아줘"
  • "채널톡 답변 템플릿 만들어줘"
  • "계약서 검토 체크리스트 만들어줘"
  • 막히면 옆 사람한테.
실습 2 — MCP 연결 (25분)
> 채널톡을 MCP로 연결해줘
  • 채널톡 or 노션 중 하나 선택
  • 연결 후: "최근 문의 요약해줘"
  • 파워유저분들 도와주세요.
실습 3 — 나만의 첫 스킬 (40분)
> 채널톡 답변 초안을 만드는 스킬을 만들어줘.
  /cs-reply로 실행할 수 있게 해줘.
  • /cs-reply — 채널톡 답변 초안
  • /daily-scrum — 데일리 스크럼
  • /research-summary — 리서치 요약
  • 설문에서 쓴 귀찮은 업무로!
내가 꿈꾸는 회사
  • AI에게 먼저 물어본다. 사람한테 묻는 건 더블체크용.
  • 필요한 게 없으면 → 스스로 만든다 → 팀에 공유
  • 문서를 사람이 보기좋게 → AI가 보기좋게
