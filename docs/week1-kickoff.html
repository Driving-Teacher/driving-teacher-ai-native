"더 잘하는 것"이 아니라 "안 하는 것"을 찾는 캠프

04—AI Native란?
≠ ChatGPT를 잘 쓰는 것
≠ 기존 업무에 AI를 붙이는 것
= AI가 있다는 전제로 업무를 재설계하는 것

AI Native가 되려면 불편해해야 합니다.
장인이 아니라 감독. 직접 만들지 않고, AI한테 시키고 검토하고.

04.5—이 캠프의 진짜 목적

아는 것을 아는 것

Known Knowns

모르는 것을 아는 것

Known Unknowns

→ 찾아보면 됨

무의식적 능력

Unknown Knowns

모른다는 것도 모르는 것

Unknown Unknowns

← 여기를 줄이는 게 핵심

"이런 것까지 되는구나"를 아는 것이 역량.
모른다는 걸 알기만 하면 — 나중에 AI한테 물어보면 되니까.

05—설문 결과

여러분이 귀찮다고 한 것들

  • 리서치/인터뷰 자료 요약에 시간이 너무 오래 걸림
  • 채널톡에서 비슷한 패턴의 답변을 반복
  • 계약서 검토, 서류 작성, 매출 프로젝션
  • 문서 포맷이 안 정해져서 매번 처음부터
  • 데일리 스크럼 쓰기

이것들을 다룰 겁니다.
