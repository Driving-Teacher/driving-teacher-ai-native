01—왜 모으나

한 명이 막히면, 다 막힙니다.

🧍

계정 1개로 같이 쓰면

그 계정 사용량 한도에 닿는 순간 전원 멈춤. 누가 많이 쓴 시간엔 다른 사람도 다 튕깁니다.

👥🔄

계정 여러 개를 풀에 모으면

요청이 round-robin으로 계정들에 번갈아 분산. 한 계정이 한도를 쳐도 나머지로 자동 우회됩니다.

즉, 내 계정 하나를 보태는 게 팀 전체의 여유가 됩니다.

02—무엇을 하나

비밀번호는 안 줍니다.
OAuth 승인만 하면 끝.

✅ 이렇게 동작

본인 ChatGPT 계정으로 로그인 → 승인하면, 풀에 OAuth 토큰만 저장됩니다. 비번·결제정보는 저장 안 됨.

🛟 안심 포인트

한 번 등록하면 끝. 언제든 빼달라고 하면 즉시 제거. 내 계정 quota만 쓰이고, 내가 쓴 내용은 공유되지 않습니다.

⚠️ URL을 여는 사람의 계정이 등록됩니다 — 꼭 본인 ChatGPT 계정으로 로그인하세요.

03—실습 — 이렇게 하면 됩니다

1인 2분. 순서만 따라오세요.

1
내 차례에 로그인 URL 받기 (1인 1개)
진행자가 한 명씩 링크를 줘요. auth.openai.com/oauth/... 로 시작.
2
본인 ChatGPT 계정으로 로그인
링크를 열면 로그인 화면이 떠요. 풀에 넣을 본인 계정으로 로그인하세요.
3
Authorize 승인
권한 허용 버튼을 누르면 됩니다.
4
리다이렉트된 주소창 URL 전체 복사
localhost:1455/auth/callback?... 로 이동해요. 페이지가 안 열려도 정상 — 주소창 URL을 끝(state=…)까지 통째로 복사.
5
진행자에게 DM으로 전달
복사한 URL을 진행자에게 보내면 끝! 등록은 진행자가 처리합니다.
