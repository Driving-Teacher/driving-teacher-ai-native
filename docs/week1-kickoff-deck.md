## Slide 3: AI Native ≠ / =

**화면**: ≠ ChatGPT 잘 쓰기 / ≠ 기존 업무에 AI 붙이기 / = 업무를 재설계

**말할 것**:
- "AI Native는 ChatGPT를 잘 쓰는 게 아닙니다."
- "기존 업무에 AI를 붙이는 것도 아닙니다."
- "AI가 있다는 전제로, 업무 자체를 재설계하는 겁니다."

## Slide 5: 바이브코딩 4단계

**화면**: Model → Context → Agent → Harness(조종석)

**말할 것**:
- "AI 코딩의 진화 단계를 빠르게 보겠습니다."
- **01 Model**: "ChatGPT에 질문하고 답변 복붙하던 시대. '이거 해줘' → 복붙."
- **02 Context**: "Cursor, Copilot 같은 도구. 내 코드를 읽고 제안해줌. '내 코드 보고 해줘'."
- **03 Agent**: "Claude Code. 터미널에서 파일을 직접 읽고 쓰고 실행까지. '알아서 해줘'. 이게 지금 대부분의 사용 방식."
- **04 Harness (조종석)**: "여기가 핵심. Claude Code에 우리 회사의 규칙, 도구, 프로세스를 미리 세팅해놓은 상태. '우리 방식대로 해줘'."
- "쉽게 말하면 — Claude Code는 빈 차, 조종석은 우리 회사에 맞게 세팅된 차입니다."
- "엔지니어링에서 Harness는 AI를 감싸서 규칙과 제약을 부여하는 레이어를 의미합니다. CLAUDE.md, Skill, MCP, Hook, Plugin — 이런 것들이 하네스의 구성 요소입니다."
- "**우리가 4주간 할 것은, 이 조종석을 우리 회사에 맞게 만드는 것입니다.**"

---

## Slide 6: 비전 — AI에게 먼저

**화면**: AS "파일 어디있죠?" → TO AI에게 먼저 물어본다

**말할 것**:
- "제가 꿈꾸는 회사 모습입니다."
- "'파일 어디있죠?', '히스토리 전해주세요', '이거 어떻게 돼요?' — 이런 걸 사람한테 안 물어도 되는 회사."
- "AI에게 먼저 물어보고, 사람한테 묻는 건 더블체크용."
- "필요한 게 있으면 검색하고, 없으면 스스로 만들고, 만들면 팀에 공유하는 문화."

## Slide 9: 7개 기능 한눈에

**화면**: Memory, Skill, MCP, Subagent, Agent Teams, Hook, Plugin

**말할 것**:
- "Claude Code의 7가지 핵심 기능을 빠르게 소개합니다. 지금 다 외울 필요 없고, 이런 게 있구나만 알면 됩니다."
- **Memory** (CLAUDE.md): "AI에게 '나는 누구고, 우리 회사는 이렇다'를 알려주는 것. 세션마다 반복 안 해도 됨."
- **Skill**: "반복하는 업무를 자동화하는 명령어. /daily-report 치면 리포트가 나오는 식."
- **MCP**: "외부 도구 연결. 채널톡, 노션, 캘린더를 AI에 꽂는 USB-C 같은 것."
- **Subagent**: "Claude가 혼자 안 되면 전문가를 부르는 것. 검색 전문가, 코드 전문가 등."
- **Agent Teams**: "여러 Claude가 팀으로 일하는 것."
- **Hook**: "특정 이벤트가 발생하면 자동으로 실행. 커밋하면 자동 리뷰 같은 것."
- **Plugin**: "다른 사람이 만든 기능을 설치해서 쓰는 것. 앱스토어 같은 개념."
- "오늘은 이 중 **MCP와 Skill**을 직접 해봅니다."
