## Slide 4: AI Native ≠ / =

**화면**: ≠ ChatGPT 잘 쓰기 / ≠ 기존 업무에 AI 붙이기 / = 업무를 재설계

**말할 것**:
- "그러면 AI Native란 뭔가? 예를 들어볼게요."
- "채널톡 CS 답변. 지금은 어떻게 하죠? 문의 읽고 → 직접 타이핑해서 답변."
- "여기에 AI를 **붙이면** — 문의 읽고 → ChatGPT에 '이거 답변해줘' → 복사 → 붙여넣기. 단계 수는 똑같아요. 이건 AI Native가 아닙니다."
- "AI 전제로 **재설계하면** — 문의가 오면 AI가 자동으로 답변 초안을 만들고, 사람은 검토만. **프로세스 자체가 달라져요.** 작성자에서 검토자로."
- "이게 AI Native입니다. ChatGPT를 잘 쓰는 게 아니라, **업무 자체를 재설계하는 것.**"
- (톤 전환) "그리고 하나 더 — **AI Native가 되려면 불편해해야 합니다.**"
- "지금 하고 있는 업무 방식이 편하다면, 그건 AI 없이도 되는 일을 하고 있다는 뜻이에요."
- "한땀한땀 장인처럼 일하는 것 — 그게 미덕이었지만, 이제는 비효율입니다."
- "AI Native는 한 번에 완벽하게가 아니라, **빠르게 여러 번**. 방향을 틀면서 결과를 내는 사람입니다."
- "장인이 아니라 감독. 직접 만들지 않고, AI한테 시키고 검토하고, 안 되면 다시 시키고."

## Slide 4.5: 이 캠프의 진짜 목적

**화면**: 지식의 4사분면 (Known/Unknown × Known/Unknown)

```
              내가 아는 것          내가 모르는 것
          ┌─────────────────┬─────────────────┐
아는 것    │ Known Knowns    │ Known Unknowns  │
          │ "나는 이걸 안다" │ "나는 이걸 모른다"│
          │                 │ → 찾아보면 됨    │
          ├─────────────────┼─────────────────┤
모르는 것  │ Unknown Knowns  │ Unknown Unknowns│
          │ "무의식적 능력"  │ "모른다는 것도   │
          │                 │  모르는 것"      │
          └─────────────────┴─────────────────┘
                                    ↑
                              여기를 줄이는 게 핵심
```

**말할 것**:
- "이 캠프의 진짜 목적은 AI를 잘 쓰는 게 아닙니다."
- "지식에는 4가지 영역이 있어요." (사분면 보여주며)
- "아는 것을 아는 것 — 여러분이 지금 잘하는 업무."
- "모르는 것을 아는 것 — '이건 모르지만 찾아보면 되지'. 이건 괜찮아요."
- "문제는 여기 — **모르는 것을 모르는 것.** Unknown Unknowns."
- "'이런 것도 할 수 있어?' — 이걸 모르면 찾아볼 수조차 없어요."
- "이 캠프에서 가장 중요한 건, **'이런 것까지 되는구나'를 알게 되는 것**입니다."
- "ChatGPT로 일하는 것도 좋지만, '여기서 뭔가 더 해볼 수 있구나'를 아는 게 역량이에요."
- "모른다는 걸 알기만 하면 — 나중에 AI한테 물어보면 되니까."

## Slide 8: 바이브코딩 4단계

**화면**: Model → Context → Agent → Harness(조종석)

**말할 것**:
- "AI를 업무에 쓰는 4단계가 있습니다. 핵심은 **비결정적 → 결정적**으로 가는 여정이에요."
- **01 Model**: "ChatGPT에 질문. 같은 질문에 매번 다른 답이 나옴. 비결정적."
- **02 Context**: "Cursor, Copilot. 내 파일을 읽으니까 맥락은 맞는데, 여전히 들쭉날쭉."
- **03 Agent**: "Claude Code. 직접 파일 읽고 쓰고 실행까지. 근데 빈 차 — 어디로 갈지 매번 달라요."
- **04 Harness (조종석)**: "여기가 핵심. 규칙, 도구, 프로세스를 미리 세팅해놓은 상태. **세팅된 차. 매번 같은 품질.** 결정적."
- "01에서 04로 갈수록, AI의 결과가 예측 가능해집니다. 운이 아니라 시스템으로 일하는 거예요."
- "**우리가 4주간 할 것은, 이 조종석을 우리 회사에 맞게 만드는 것입니다.**"

## Slide 9: 7개 기능

**화면**: Memory, Skill, MCP (하이라이트) + 나머지 4개 (흐림)

**말할 것**:
- "Claude Code의 7가지 핵심 기능입니다. 크게 **2가지 축**으로 나뉩니다."
- (축 1) "**결정화** — AI의 결과를 예측 가능하게 만드는 기능들:"
- **Memory**: "AI에게 '나는 누구고, 우리 회사는 이렇다'를 알려주는 것. 매번 처음부터 설명 안 해도 됨."
- **Skill**: "반복 업무를 명령어 하나로. 예를 들어 `/think-deeper` — 팀 빌딩에서 '일단 처리하는 습관'을 문제로 잡았잖아요. 그래서 제가 만든 스킬입니다. 이런 식으로 매번 다른 결과가 나오는 AI를 **매번 같은 품질**로 만드는 게 스킬입니다."
- (축 2) "**확장** — AI가 할 수 있는 것 자체를 늘리는 기능:"
- **MCP**: "외부 도구 연결. 채널톡, 노션을 AI에 꽂는 USB-C. MCP 없으면 AI는 여러분 컴퓨터의 파일만 볼 수 있어요. MCP 있으면 노션, 슬랙, 웹 검색까지."
- "나머지 4개 — Subagent, Teams, Hook, Plugin — 이건 쓰면서 자연스럽게 알게 됩니다."
- "오늘은 **Memory + Skill(결정화) + MCP(확장)** 3개를 직접 해봅니다. 더 궁금하면 `/claude-code-guide`."
