## Slide 3: AI Native ≠ / =

**화면**: ≠ ChatGPT 잘 쓰기 / ≠ 기존 업무에 AI 붙이기 / = 업무를 재설계

**말할 것**:
- "AI Native는 ChatGPT를 잘 쓰는 게 아닙니다."
- "기존 업무에 AI를 붙이는 것도 아닙니다."
- "AI가 있다는 전제로, 업무 자체를 재설계하는 겁니다."

## Slide 6: 비전

## Slide 8: 바이브코딩 4단계

**화면**: Model → Context → Agent → Harness(조종석)

**말할 것**:
- "AI 코딩의 진화 단계를 빠르게 보겠습니다."
- **01 Model**: "ChatGPT에 질문하고 답변 복붙하던 시대."
- **02 Context**: "Cursor, Copilot 같은 도구. 내 코드를 읽고 제안해줌."
- **03 Agent**: "Claude Code. 터미널에서 파일을 직접 읽고 쓰고 실행까지. 빈 차."
- **04 Harness (조종석)**: "여기가 핵심. Claude Code에 우리 회사의 규칙, 도구, 프로세스를 미리 세팅해놓은 상태. 세팅된 차."
- "**우리가 4주간 할 것은, 이 조종석을 우리 회사에 맞게 만드는 것입니다.**"

---

## Slide 9: 7개 기능

**화면**: Memory, Skill, MCP (하이라이트) + 나머지 4개 (흐림)

**말할 것**:
- "Claude Code의 7가지 핵심 기능입니다. 다 외울 필요 없고, 이런 게 있구나만."
- **Memory**: "AI에게 '나는 누구고, 우리 회사는 이렇다'를 알려주는 것."
- **Skill**: "명령어 하나로 실행하는 자동화. 예를 들어 `/think-deeper` — 팀 빌딩에서 우리가 '일단 처리하는 습관'을 문제로 잡았잖아요. 장기적으로 생각할 자리가 없다고. 그래서 제가 만든 스킬입니다. 고민을 넣으면 4단계로 전략적 사고를 도와줘요. 이런 식으로 반복되는 업무나 고민을 스킬로 만들어서 `/명령어`로 실행하는 것."
- **MCP**: "외부 도구 연결. 채널톡, 노션을 AI에 꽂는 USB-C 같은 것."
- "나머지 4개 — Subagent, Teams, Hook, Plugin — 이건 쓰면서 자연스럽게 알게 됩니다."
- "오늘은 이 위 **3개**를 직접 해봅니다. 더 궁금하면 `/claude-code-guide`."

## Slide 10: /think-deeper 소개

**화면**: /think-deeper — 4단계 (문제 정의 → Plan A/B/C → 임기응변 체크 → 기획 문서)

**말할 것**:
- "스킬의 예시를 하나 보여드릴게요."
- "팀 빌딩에서 우리가 문제로 잡았던 거 기억하시죠? '일단 처리하는 습관'. 장기적으로 생각하는 자리가 없다고."
- "그래서 제가 만들어온 스킬입니다. `/think-deeper`."
- "고민을 넣으면 4단계로 진행됩니다."
- "1. 왜 해야 하는지 5 Whys로 근본 원인까지 파고듦"
- "2. Plan A/B/C를 동시에 — 성공뿐 아니라 '이게 안 되면?'도 같이"
- "3. 이거 시스템인가 땜빵인가 체크"
- "4. 그리고 이 답변들을 모아서 기획 문서를 자동으로 만들어줍니다."
- "이런 걸 여러분도 직접 만들 겁니다. 자기 업무에 맞는 스킬을."
- "숙제로도 이걸 써보는 게 있습니다."
