## Week 1 — L1 "시켜본다" (개인 생산성)

### 과제 1.1 · AI 우선 일지 (매일 1줄)
- 매일 마주친 일 중 1개를 **"사람에게 묻기 전에 AI에게 먼저"** 시켜본 기록
- 형식: `[날짜] 물어본 것 / AI 결과 / 사람 답변과 비교 / 시간 절감 여부`
- **딜리버러블**: 주말까지 5개 누적, 슬랙 `#ai-native`에 매일 1줄

### 과제 1.2 · 반복 업무 인벤토리
- 이번 주 한 일 중 **"또 할 가능성 높은 반복 업무"** 3개 리스팅
- 각각 "이거 AI한테 시킬 수 있나?" 1~5점
- **딜리버러블**: 메모 1개 (위치 자유 — 본인 노션이든 슬랙이든)

### 과제 1.3 · 첫 스킬 1개
- 1.2의 상위 1개를 스킬로 (1-Day 세션에서 만들어둔 게 있으면 그걸로)
- **딜리버러블**: `~/.claude/skills/<이름>/SKILL.md` 1개 + 1번 이상 실사용

## Week 2 — L1.5 "팀에 풀기"

### 과제 2.1 · 스킬을 회사 전체에 풀기
- Week 1에서 만든 스킬이 **다른 팀원에게도 가치 있다고 판단되면**:
  - **Zeude 대시보드 > Skills 탭 > 스킬등록** (셀프 서비스, 모든 멤버 admin)
  - 슬랙 `#ai-native`에 "나 이거 만들었어, 써봐" 1번 소개
- KB 노션 데이터를 다루는 스킬이면 → KB 레포 `.claude/skills/`에 PR
- ※ 살림터 분류는 [README "스킬 살림터" 3-tier](../README.md#스킬-살림터--어디에-뭘-두나) 참고
- **딜리버러블**: Zeude 등록 스크린샷 또는 PR 링크 + 슬랙 공유 1번

### 과제 2.2 · 노션 MCP 연결
- Claude Code에 노션 MCP 붙이기 → 본인 도메인 노션 페이지를 Claude가 직접 읽게
- 시험 질문: "이번 분기 ○○ 관련 노션 페이지 전부 요약해줘" → 진짜 노션에서 끌어오는지
- **딜리버러블**: MCP 설정 완료 + 첫 질의 결과 1번 슬랙 공유

### 과제 2.3 · 두 번째 스킬 또는 기존 스킬 개선
- Week 1 스킬을 1주 실사용하고 **모호했던 부분 개선**
- 또는 1.2 인벤토리의 다음 후보를 스킬로
- **딜리버러블**: git log에 변경 이력 1개 이상

## Week 3~4 — L2 "안 해도 되는 일 제거" 🎯 (핵심)

### 과제 3.1 · 제거 후보 1개 선언
- 본인 업무 중 **"매주 손으로 하지만 사실 AI/스킬에 맡길 수 있는 일"** 1개 선언
- 후보 예시 (도메인별):
  - 마케팅/성장팀: 주간 리포트 초안, 캠페인 카피 1차 검토, 발송 캘린더 정리
  - CS: 반복 문의 응답 초안, FAQ 갱신, 채널톡 트리아지
  - 운영: SOP 정리, 주간 회의록 요약, 데이터 조회
- **딜리버러블**: 슬랙에 "다음 주 1주간 ___를 안 손으로 하고 AI에 맡깁니다" 선언

### 과제 3.2 · 실제로 1주 안 하기
- 3.1의 일을 **1주 동안 손으로 안 하고** AI/스킬에 시키기
- 기록:
  - (a) 문제없이 굴러갔는지
  - (b) 어디서 부족했는지 (사람이 채워야 했던 부분)
  - (c) 절약된 시간 추정
- **딜리버러블**: 회고 메모 1개 (슬랙 또는 KB)

### 과제 3.3 · 결정
- 3.2 결과로:
  - **잘 굴러갔다** → 영구히 AI 담당으로 선언 (1줄 선언문)
  - **부족했다** → 필요한 컨텍스트(KB·CLAUDE.md·MCP) 정리 후 보완. 안 되면 그 일은 사람 영역으로 유지.
- **딜리버러블**: 결정 1줄 + (보완 필요시) 추가 작업 목록

## Week 5+ — L3 "팀 운영 재설계" (선택, 누적 도전)

### 과제 4.1 · 본인 팀 프로세스 1개를 AI 전제로 재설계
- 예시 (도메인별):
  - 주간 회의를 "Hermes가 매주 월요일 KPI/캠페인 요약 슬랙 DM → 회의는 검토만"으로
  - 신규 캠페인 기획을 "AI가 초안 → 본인은 검토·조정만"으로
  - 정기 보고서를 "AI 자동 생성 → 본인은 인사이트만 추가"로
- 1달 시도 후 회고
- **딜리버러블**: 재설계 전/후 메모 + 1달 실천 후 회고

### 과제 4.2 · AI Native 선언문 최종판
- "____는 제거하고, 그 시간에 ____ 하겠다" 빈칸 채우기
- 슬랙 `#ai-native`에 공개
- 1개월 실천 → 회고 (캠프 W4 형식과 동일)
- **딜리버러블**: 최종 선언문 1줄 + 1개월 회고
