07—Git

Git 최소 생존 키트

노션이 문서를 저장하는 곳이면, Git은 코드를 저장하는 곳. 스킬을 올리면 팀 전원이 씁니다.

# 받기 (처음 한 번)
$ git clone https://github.com/Driving-Teacher/driving-teacher-ai-native.git
$ git clone https://github.com/Driving-Teacher/driving-teacher-knowledge-base.git
# 당기기 (최신으로)
$ git pull
# 올리기 (3줄 세트)
$ git add .
$ git commit -m "메시지"
$ git push

부딪힐 것들

  • Permission denied → gh auth login
  • 충돌 → git pull 하고 다시 push
  • 안 되면 → Claude한테 "git push 해줘"

모르면 Claude한테 물어보세요. Git 명령어도 Claude가 다 알아요.
