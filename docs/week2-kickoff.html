04—Git 최소 생존 키트
$ git clone [url] ← 다운로드
$ git pull ← 최신으로
$ git add . ← 올릴 거야
$ git commit -m "메시지" ← 확정
$ git push ← 업로드

충돌나면? git pull → 다시 push
