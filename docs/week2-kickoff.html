04—꿀팁

잘 쓰는 사람들의 비결

지난주에 잘 되는 것도 안 되는 것도 있었을 거예요.

  • CLAUDE.md — Claude가 모를 것만 넣으세요. 200줄 넘기지 마세요.
  • 스킬 — description이 제일 중요. '왜'를 설명하면 결과가 좋아요.
  • 에러 — 에러 붙여넣고 'fix' 한 마디. 과도한 설명은 오히려 방해.
  • 컨텍스트 — 길어지면 /compact. 막히면 /clear하고 새로 시작.

/tips 치면 더 많은 팁

내 팁도 공유하세요 — 팀 집단지성
범용 Claude 팁 → docs/tips.md에 add + push (ai-native, public)
회사 업무 팁 → knowledge-base/tips/에 add + push (private)
Claude한테 "이 팁을 적절한 곳에 추가해줘" 하면 알아서 정리

그리고 제일 중요한 건 — 스스로 계속 찾는 것.
이걸 말하는 이 순간에도 더 좋은 도구가 나오고 있어요.
웹 검색으로 끊임없이 내가 필요한 툴을 찾아오세요.

08—Git

Git 최소 생존 키트

Git = 공동 폴더.
도메인 지식·노션 sync·KB 데이터 스킬을 knowledge-base에 push →
팀원이 pull → 같은 데이터·KB-스코프 스킬을 공유
※ 회사 전체 글로벌 스킬은 Zeude (앞 슬라이드 참고)

# 업무 스킬·도메인 지식 받기 (처음 한 번)
$ git clone https://github.com/Driving-Teacher/driving-teacher-knowledge-base.git
# 당기기 → 올리기 (3줄 세트)
$ git pull
$ git add . && git commit -m "메시지" && git push
09—Git — 부딪힐 것들
  • Permission denied → gh auth login
  • 충돌 → git pull 하고 다시 push
  • 안 되면 → Claude한테 "git push 해줘"

두 레포 구분

  • driving-teacher-ai-native · public · 커리큘럼 스킬 (day1, day2…)
  • driving-teacher-knowledge-base · private · 도메인 지식(노션 sync) + KB 데이터 스킬 (예: /kb)

회사 전체 스킬 배포는 Git push가 아니라 Zeude 대시보드 > Skills 탭으로 (셀프 등록).

모르면 Claude한테 물어보세요. Git도 Claude가 다 알아요.

10—페어 실습

짝지어서 회사 문제 하나를 AI로

60min
  • 팀 1 — 오석준 + 정재만
  • 팀 2 — 임재현 + 정기흥
  • 팀 3 — 이희준 + 조성진
  • 고민 공유 (5분) → 하나 선택
  • 분담해서 풀기 (40분)
  • 합치고 push (15분)
