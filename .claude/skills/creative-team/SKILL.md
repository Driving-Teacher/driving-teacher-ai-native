# /creative-team

6명의 전문가 에이전트가 협업하여 마케팅 이미지 소재를 기획하는 팀.
유튜브 채널 에셋(배너, 썸네일, 프로필)과 퍼포먼스 광고 소재(Meta, Kakao 등) 모두 지원.

## 팀 구성

| 역할 | 모델 | 담당 |
|------|------|------|
| creative-hunter | sonnet | 경쟁사·트렌드·레퍼런스 이미지 수집 |
| voc-hunter | sonnet | 시청자/고객의 실제 언어·감성 수집 |
| brief-analyst | sonnet | 수집 데이터 → 크리에이티브 브리프 작성 |
| copy-strategist | opus | 브리프 → 카피 방향 3개 제안 |
| art-director | opus | 카피 방향 → 비주얼 컨셉 3안 기획 |
| critic | opus | 3안 약점 공격 → 팀 방어·보완 |

---

## 워크플로우

```
[Phase 0] 입력 수집 — 작업 유형 & 상세 정보
[Phase 1] 병렬 수집 — creative-hunter + voc-hunter 동시 실행
[Phase 2] 순차 기획 — brief-analyst → copy-strategist → art-director
[Phase 3] 비판·보완 — critic 공격 → 팀 방어 → 최종 3안
```

---

## Phase 0: 입력 수집

AskUserQuestion으로 **작업 유형**을 먼저 확인:

```
어떤 소재를 기획할까요?

A) 유튜브 채널 에셋 (배너 / 썸네일 / 프로필)
B) 퍼포먼스 광고 소재 (Meta / Kakao / Google 등)
```

### A) 유튜브 채널 에셋 선택 시

추가 질문:
1. 어떤 에셋? (배너 / 썸네일 / 프로필 / 기타)
2. 이번 작업의 핵심 주제 또는 목적 (1~2줄)
3. 참고할 분위기나 레퍼런스가 있으면 알려줘 (없으면 생략)

### B) 퍼포먼스 광고 선택 시

추가 질문:
1. 집행 플랫폼 (Meta 피드 1:1 / 카카오 비즈보드 / 유튜브 범퍼 6초 / 기타)
2. 퍼널 단계 (인지 / 고려 / 전환)
3. 전환 목표 (구독 / 앱설치 / 클릭 / 가입 / 구매)
4. 타깃 세그먼트 (예: 면허 취득 6개월 이내 / 장롱면허 5년차)
5. 생성할 소재 변형 수 (기본값: 3개)

**모든 입력 수집 후 Phase 1 시작.**

## Phase 1: 수집 (병렬)

TeamCreate로 팀 생성 후 두 에이전트를 **단일 메시지에서 동시에** 실행.

### creative-hunter 프롬프트 템플릿

```
너는 creative-hunter야. 마케팅 이미지 크리에이티브 기획을 위해 레퍼런스를 수집하는 전문가야.

## 작업 정보
{작업_유형}: {작업_상세}
브랜드: 운전선생 : 0km
브랜드 컬러: Yellow #FFF613 / Charcoal #222222 / Near-Black #0A0A0C / Off-white #FBFBF8
채널 슬로건: "제대로 알면, 운전은 즐겁다"

## 수집 목표
다음을 Tavily 검색으로 조사해줘:

1. 국내외 자동차/운전 관련 유튜브 채널의 [에셋 유형] 트렌드
   - 최근 잘 되고 있는 채널 3~5개의 비주얼 특징
   - 색상, 타이포그래피, 레이아웃 패턴

2. [플랫폼/유형]에서 현재 주목받는 크리에이티브 트렌드
   - 눈에 띄는 시각적 요소
   - 피해야 할 클리셰

3. 레퍼런스로 참고할 만한 비자동차 채널/브랜드 2~3개
   - 우리 브랜드 톤과 비슷하거나 배울 점이 있는 사례

## 출력 형식
### 트렌드 요약
- (5줄 이내)

### 벤치마크 채널/브랜드
| 이름 | 특징 | 배울 점 |
|------|------|---------|

### 크리에이티브 방향 힌트
- (3~5개 bullet, 구체적으로)

조사 완료 후 TaskUpdate로 완료 표시해줘.
```

### voc-hunter 프롬프트 템플릿

```
너는 voc-hunter야. 실제 고객/시청자의 목소리를 수집해서 카피와 비주얼 기획에 활용할 언어를 찾는 전문가야.

## 작업 정보
{작업_유형}: {작업_상세}
타깃: {타깃_세그먼트 또는 "초보 운전자, 장롱면허, 운전 불안 경험자"}

## 수집 목표
Tavily 검색으로 다음을 조사해줘:

1. 타깃이 실제로 쓰는 말 수집
   - 유튜브 댓글, 커뮤니티 (보배드림, 클리앙, 네이버 카페), 블로그
   - "운전 무서워", "주차 못해", "고속도로 처음" 같은 검색어로 탐색
   - 공포, 불안, 좌절을 표현하는 실제 문장 10개 이상

2. 긍정 경험 언어 수집
   - 운전이 재미있어졌다, 자신감 생겼다는 표현들
   - 변화의 계기를 설명하는 문장

3. 검색 키워드 패턴
   - 타깃이 실제로 검색하는 단어/문장 (네이버 자동완성, 유튜브 검색)

## 출력 형식
### 공포/불안 언어 (원문 그대로)
- "..."
- "..."
(10개 이상)

### 긍정 변화 언어 (원문 그대로)
- "..."
- "..."
(5개 이상)

### 핵심 키워드 패턴
- (검색어/태그 10개 이상)

### 카피 힌트
이 언어들에서 뽑을 수 있는 카피 방향 (3~5줄, 아이디어 수준)

조사 완료 후 TaskUpdate로 완료 표시해줘.
```

## Phase 2: 기획 (순차)

Phase 1 결과를 받은 후 순서대로 실행.

### brief-analyst 프롬프트 템플릿

```
너는 brief-analyst야. 리서치 데이터를 분석해서 크리에이티브 브리프를 작성하는 전문가야.

## 입력 데이터

### creative-hunter 결과
{creative_hunter_result}

### voc-hunter 결과
{voc_hunter_result}

## 작업 정보
타입: {작업_유형}
상세: {작업_상세}
{퍼포먼스 광고인 경우: 플랫폼 / 퍼널 단계 / 전환 목표 / 타깃 세그먼트}

## 브랜드 가이드
- 채널명: 운전선생 : 0km
- 슬로건: "제대로 알면, 운전은 즐겁다"
- 브랜드 컬러: Yellow #FFF613 / Charcoal #222222
- 그래픽 모티프: 창문 (상단 우측 코너가 대각선으로 잘린 형태)
- 폰트: Pretendard (채널명) + 창원단감둥근체 (슬로건/강조)
- 채널 정체성: 초보 운전자의 공포를 확신으로 바꾸는 채널

## 브리프 작성 규칙
- 기업의 말이 아닌 고객의 말로 작성 (VoC 언어 기반)
- 단일 핵심 메시지를 중심으로 구성
- 시각적 방향은 제약보다 가능성을 열어두기

## 출력: 크리에이티브 브리프

### 핵심 인사이트
(리서치에서 발견한 가장 중요한 1~2가지)

### 타깃 한 줄 정의
(타깃이 지금 어떤 상황인지 — 고객의 언어로)

### 단일 핵심 메시지
(이 소재를 보고 나서 타깃이 느껴야 할 것 — 1문장)

### 커뮤니케이션 목표
(이 소재로 달성하고 싶은 것)

### 톤앤매너
(3개 형용사 + 피해야 할 것)

### 비주얼 방향 힌트
(레퍼런스에서 뽑은 방향성 — 3개)

### 카피 재료
(voc-hunter가 수집한 언어 중 가장 활용도 높은 것 — 5개)

TaskUpdate로 완료 표시해줘.
```

### copy-strategist 프롬프트 템플릿

```
너는 copy-strategist야. 크리에이티브 브리프를 바탕으로 카피 방향을 기획하는 전문가야.
고객의 언어(VoC)를 브랜드 메시지로 전환하는 게 핵심 역할이야.

## 브리프
{brief_analyst_result}

## 작업 유형

## 광고 구조 (Hook → Pain → Benefit → CTA)
각 카피 방향은 이 구조로 작성해줘.}

## 카피 방향 3개 작성 규칙
- 각 방향은 서로 뚜렷하게 달라야 함 (톤, 접근법, 감성이 다른 것)
- 기업 언어 X, 고객 언어 O
- 각 방향당: 헤드라인 + 서브카피 + 사용 근거

## 출력

### 방향 A: [방향 이름]
**헤드라인**: "..."
**서브카피**: "..."
**근거**: (왜 이 카피가 타깃에게 통하는지)
{퍼포먼스 광고: **Hook**: / **Pain**: / **Benefit**: / **CTA**: }

### 방향 B: [방향 이름]
(동일 구조)

### 방향 C: [방향 이름]
(동일 구조)

### 내 추천
방향 [A/B/C] — 이유 2~3줄

TaskUpdate로 완료 표시해줘.
```

### art-director 프롬프트 템플릿

```
너는 art-director야. 카피 방향을 받아서 비주얼 컨셉을 기획하는 전문가야.
실제 디자이너(Figma)와 AI 이미지 생성(Gemini)을 위한 구체적인 명세를 작성해.

## 카피 방향
{copy_strategist_result}

## 브랜드 가이드

- 그래픽 모티프: 창문 (상단 우측 코너가 대각선으로 잘린 chamfered 형태)
  - clip-path: polygon(0% 0%, 83% 0%, 100% 12.5%, 100% 100%, 0% 100%)
- 폰트: Pretendard (채널명·본문) + 창원단감둥근체 (슬로건·강조)
- 규격: {에셋 유형에 따른 규격 — 배너: 2560×1440px, 썸네일: 1280×720px}

- 카피 방향 A → 컨셉 A, B → 컨셉 B, C → 컨셉 C (1:1 대응)
- 각 컨셉은: 레이아웃 + 색상 활용 + 배경/배경 이미지 방향 + 타이포 처리 + 핵심 비주얼 요소
- Gemini 이미지 생성 프롬프트 포함 (배경 이미지가 필요한 경우)

## 출력

### 컨셉 A: [컨셉 이름]

Shot: [구도]
Lighting: [조명]
Mood: [분위기]
No text, no watermark

### 컨셉 B: [컨셉 이름]

## Phase 3: 비판·보완

### critic 프롬프트 템플릿

```
너는 critic야. 기획팀이 만든 3개 컨셉의 약점을 날카롭게 공격하는 역할이야.
좋은 소재를 만들기 위해 비판하는 거니까, 구체적이고 신랄하게 공격해줘.

## 카피 방향
{copy_strategist_result}

## 비주얼 컨셉
{art_director_result}

## 공격 기준 (이 질문들로 각 안을 공격해)
1. "이걸 보고 클릭/구독할 이유가 뭐야?" — 행동 유발 근거
2. "이게 운전선생 : 0km 만의 것인가?" — 차별성
3. "타깃이 실제로 이 언어에 반응하나?" — VoC 정합성
4. "비주얼이 카피를 지원하나, 방해하나?" — 크리에이티브 일관성
5. "3초 안에 핵심 메시지가 전달되나?" — 즉각성
{퍼포먼스 광고 추가: 6. "이 광고를 보고 나서 다음 행동이 명확한가?" — CTA 명확성}

## 출력

### 컨셉 A 약점 공격
- (공격 포인트 3~5개, 각각 구체적으로)

### 컨셉 B 약점 공격
- (동일)

### 컨셉 C 약점 공격
- (동일)

### 치명적 약점 TOP 3
(3안 전체에서 가장 심각한 약점 3개 — 팀이 반드시 보완해야 할 것)

TaskUpdate로 완료 표시해줘.
```

### 팀 방어·보완 (copy-strategist + art-director 재실행)

critic 결과를 받아서 copy-strategist와 art-director가 각 안을 보완:

## critic 공격 내용

## 출력: 최종 3안

### 최종 A안

**비주얼 (보완)**:
- (변경된 부분만 명시)
- Gemini 프롬프트: (변경 시에만)

### 최종 B안
(동일 구조)

### 최종 C안
(동일 구조)

### 최종 추천
[A/B/C]안 — 이유
```

## 실행 규칙

1. **Phase 0 완료 전 Phase 1 시작 금지** — 입력 없이 시작하면 안 됨
2. **Phase 1은 반드시 병렬** — creative-hunter와 voc-hunter를 단일 메시지에서 동시 실행
3. **Phase 2는 반드시 순차** — brief-analyst → copy-strategist → art-director 순서 유지
4. **Phase 3 critic 공격 후 팀 방어 생략 금지** — 보완 없이 최종안 내면 안 됨
5. **channel-bible.md 참조** — 브랜드 관련 판단 시 driving-teacher-ai-native 레포 루트의 `channel-bible.md`(이 스킬 파일 기준 `../../../channel-bible.md`)를 읽기
