## Block 1: 숙제 공유 + Zeude 리뷰 (~10분)

> 슬라이드 04(Zeude 데이터) → 05(숙제) 순서.

### 진행

1. **Hermes 사용 경험 공유** (slide 05 — 손들기 + 인상적 1명만 30초):

```json
AskUserQuestion({
  "questions": [{
    "question": "지난주 Hermes 어떻게 쓰셨나요?",
    "header": "숙제 공유",
    "options": [
      {"label": "자주 썼다", "description": "매일 / 여러 번 / 어디서?"},
      {"label": "가끔 썼다", "description": "한두 번 떠올랐다"},
      {"label": "잘 안 썼다", "description": "왜 안 됐는지 솔직 답변"},
      {"label": "AI한테 먼저 물어본 경험", "description": "사람보다 AI 먼저"}
    ],
    "multiSelect": true
  }]
})
```

2. **Zeude 대시보드 리뷰** (slide 04):

```
Zeude를 열어서 지난 2주 데이터를 봅시다.
- 누가 가장 많이 썼나?
- 어떤 스킬이 가장 많이 사용됐나?
- 사용량 트렌드는?
```

> 📌 **Zeude 접속 실패 시 fallback**: 슬라이드 04에 박힌 사전 캡처 데이터 사용. 호스트가 미리 스크린샷 준비.

## Block 2.5: Before / After 1인 ~3분 (~25-30분, 메인 회고)

> 슬라이드 06.5. **cliproxy 인계 시간 빼고 회고/공유에 집중하는 핵심 블록.**

```
이제 추상에서 구체로 갑니다.
한 명씩 2-3분 — "4주 전의 나" / "지금의 나" 한 줄씩.

예시:
  Before: "AI한테 시키면 답이 이상해서 그냥 내가 함"
  After:  "Hermes에 한 줄 던지는 게 먼저"

박주영 님 변형:
  Today:  "오늘 처음 출근"
  +30 days: (가설) "박주영의 첫달 가설 한 줄"
```

호스트 진행 메모:
- 한 명당 ~3분 (8명 + 박주영 = ~25-30분). 평균만 맞으면 OK
- **공감/리액션 시간 포함** — 한 줄 던지면 다른 사람이 "오 그거 나도", "어떻게?" 같은 짧은 반응
- 답이 안 떠오르는 사람은 패스 OK — 다음 사람으로
- 인상적 답변 1~2개는 호스트가 받아서 slide 07 강사 한 줄과 연결
- 모두 끝나면 → 호스트가 슬라이드 07 (캠프 결론) 으로 점프

> ⚠️ 시간 초과 시: 박주영 변형은 짧게(1분), 또는 호스트가 "다음에 슬랙으로 마저 나누자" 안내 후 선언으로 점프

> 청중 답변 패턴이 보이면 호스트가 자기 한 줄로 받아 슬라이드 07(강사 한 줄)로 넘김:
> **"AI Native는 도구를 잘 쓰는 게 아니라, 안 해도 되는 일을 발견하고 제거하는 것입니다."**

## Block 3: AI Native 선언 (~10분)

> 슬라이드 12 → 13.

### 1. 호스트가 먼저 선언 (모범 사례 — 30초)

```
[호스트 본인 선언 예시]
"수동 데일리 리포트 작성을 제거하고, 그 시간에 팀원 1on1을 늘리겠다."
```

### 2. 청중 선언 받기

```json
AskUserQuestion({
  "questions": [{
    "question": "___를 제거하고, 그 시간에 ___를 하겠다.",
    "header": "AI Native 선언",
    "options": [
      {"label": "수동 리포트 → 고객 인사이트 분석", "description": "리포트는 AI가, 나는 분석을"},
      {"label": "채널톡 반복 답변 → 답변 품질 개선", "description": "초안은 스킬이, 나는 톤 조정을"},
      {"label": "파일 위치 물어보기 → 문서 구조 개선", "description": "검색은 AI가, 나는 정리를"},
      {"label": "직접 쓸게 (자유 입력)", "description": "위에 없으면 나만의 한 줄"}
    ],
    "multiSelect": false
  }]
})
```

> "직접 쓸게" 선택 시 → 자유 텍스트 받기:
>
> ```
> 어떤 한 줄로 박을까요? 
> "___를 제거하고, ___를 하겠다." 형식으로 말씀해주세요.
> ```

### 3. 박주영 님 변형 (신입 1명)

```json
AskUserQuestion({
  "questions": [{
    "question": "박주영 님 — 첫날 가설 한 줄.",
    "header": "박주영 변형",
    "options": [
      {"label": "내가 AI에게 가장 먼저 시키고 싶은 일 1개", "description": "첫날의 가설"},
      {"label": "기존 7명과 같이 ___제거 / ___실행 형식", "description": "가설 대신 선언"}
    ],
    "multiSelect": false
  }]
})
```
