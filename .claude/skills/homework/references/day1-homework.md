# Day 1 숙제

## 출력할 내용

```
📝 Week 1 숙제: 첫 스킬 실전 + /think-deeper

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ 숙제 1: CLAUDE.md 작성 (필수)

Claude가 "나"를 아는 상태로 대화를 시작하게 만드세요.

Claude Code에 이렇게 말하면 됩니다:
  "CLAUDE.md에 내 정보를 추가해줘.
   나는 [이름]이고, [역할]이야.
   주요 업무는 [업무들]이야."

다 쓰면 새 세션 열어서 Claude가 나를 기억하는지 확인!


✅ 숙제 2: 만든 스킬 실전 사용 (필수)

오늘 만든 스킬을 실제 업무에 써보세요.
  - 잘 되면 → 슬랙에 공유
  - 안 되면 → 뭐가 안 됐는지 기록 (다음 주에 고칠 거)


✅ 숙제 3: /think-deeper 체험 (필수)

Claude Code에서 /think-deeper를 실행해보세요.
자기 업무 중 고민인 것 1개를 주제로 넣으면 됩니다.

  예시 주제:
  💡 "학생 이탈률을 줄이려면?"
  💡 "CS 응대 시간을 단축하려면?"
  💡 "학원 온보딩을 더 쉽게 하려면?"

→ 나온 기획 문서를 슬랙에 공유!


🔥 숙제 4: "안 해보기" 실험 (도전)

이번 주에 평소 하던 업무 중 1개를 안 해보세요.
  안 해도 아무 문제 없었다면 → 제거 성공! 🎉
  문제가 생겼다면 → 그것도 배움입니다

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
⏰ 마감: 다음 세션 전까지
📍 공유: 슬랙 #ai-native-log
```
