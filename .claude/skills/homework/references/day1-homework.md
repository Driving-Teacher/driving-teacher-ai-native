📝 Week 1 숙제

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ 숙제 1: CLAUDE.md 만들기 (필수)

실습에서 Auto Memory로 자기 정보를 기억시켰죠?
이번엔 CLAUDE.md를 만들어보세요 — Claude에게 주는 매뉴얼입니다.

Claude Code에 이렇게 말하면 됩니다:
  "CLAUDE.md를 만들어줘.
   나한테 답변할 때 지켜야 할 규칙을 정리해줘."

예시:
  - 한국어로 대화해
  - 표로 정리해줘
  - 길게 설명하지 말고 핵심만
  - 존댓말 써

Auto Memory = Claude가 알아서 적는 메모 (실습에서 해본 것)
CLAUDE.md = 내가 직접 적는 매뉴얼 (이 숙제)

다 쓰면 새 세션 열어서 Claude가 매뉴얼대로 하는지 확인!


✅ 숙제 2: /think-deeper로 내 문제 해결책 가져오기 (필수)

지금 업무에서 가지고 있는 문제를 하나 골라서
/think-deeper로 해결책을 만들어보세요.

Claude Code에 /think-deeper 를 입력하고,
질문에 답하면 해결책이 담긴 기획 문서가 나옵니다.

결과를 #ai-native에 공유해주세요.
"이런 문제를 넣었더니 이런 해결책이 나왔다" 정도면 OK.


✅ 숙제 3: MCP로 실제 업무 1개 해보기 (필수)

실습에서 연결한 MCP로 진짜 업무를 시켜보세요.

예시:
  - 노션 → "지난주 회의록 요약해줘"
  - 슬랙 → "이번 주 나한테 온 메시지 정리해줘"
  - Tavily → "경쟁사 ___에 대해 리서치해줘"
  - 채널톡 → "최근 자주 오는 문의 패턴 분석해줘"

결과를 #ai-native에 공유 — "이런 걸 시켰더니 이렇게 나왔다"

  ⚠️ 실습에서 MCP 연결 못 했다면 → 먼저 연결부터!
  Claude Code에 "노션 MCP 연결해줘" 라고 시키면 됩니다.

  스킬을 만들어보세요.
  "___를 자동화하는 스킬 만들어줘" 라고 Claude에게 시키면 됩니다.
