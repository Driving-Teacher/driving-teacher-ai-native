실습에서 Auto Memory로 자기 정보를 기억시켰죠?
이번엔 프로젝트 CLAUDE.md를 만들어보세요.

Claude Code에 이렇게 말하면 됩니다:
  "이 프로젝트의 CLAUDE.md를 만들어줘.

다 쓰면 새 세션 열어서 Claude가 규칙을 지키는지 확인!
