# /youtube-team

영상 한 편을 만들 때마다 실행하는 콘텐츠 제작 기획팀.
트렌드 리서치부터 스크립트 + 썸네일 브리프까지 한 번에 뽑아낸다.

## 팀 구성

| 역할 | 모델 | 담당 |
|------|------|------|
| trend-hunter | sonnet | 트렌드 & 키워드 리서치 |
| youtube-strategist | sonnet | 주제 확정, 제목 후보 3개, 트랙 배정 |
| script-architect | opus | 스크립트 작성 (후크 → 원리 → 실전) |
| thumbnail-designer | sonnet | 썸네일 카피 + 구도 브리프 |

---

## 워크플로우

```
[Phase 0] 입력 수집 — 주제 아이디어 또는 "자유 발굴"
[Phase 1] trend-hunter — 트렌드 & 키워드 리서치
[Phase 2] youtube-strategist — 주제·제목·트랙 확정
[Phase 3] script-architect + thumbnail-designer — 병렬 실행
[Phase 4] 결과 정리 & 파일 저장
```

---

## Phase 0: 입력 수집

AskUserQuestion으로 시작 방식 확인:

```
이번 영상 어떻게 시작할까?

A) 주제 아이디어가 있어 → 아이디어 한 줄로 알려줘
B) 트렌드 보고 자유롭게 발굴해줘
```

### A 선택 시
- 주제 아이디어 (예: "고속도로 진입 공포 극복", "주차 왕초보 가이드")
- 추가로 고려할 조건이 있으면 알려줘 (없으면 생략)

### B 선택 시
- 별도 입력 없이 trend-hunter가 자유롭게 탐색

**입력 확인 후 Phase 1 시작.**

## Phase 1: trend-hunter

### 프롬프트

```
너는 trend-hunter야. 운전선생 : 0km 유튜브 채널의 다음 영상 주제를 찾기 위해
트렌드와 키워드를 리서치하는 전문가야.

## 채널 정보
- 채널명: 운전선생 : 0km
- 슬로건: "제대로 알면, 운전은 즐겁다"
- 타깃: 초보 운전자, 장롱면허, 운전 불안 경험자
- 콘텐츠 트랙:
  - Track 1 [비밀 과외]: 운전 원리 교육 (주 1회, 수요일)
  - Track 2 [심장아 진정해]: 공포/불안 극복 (격주 토요일)
  - Track 3 [달리면서 듣는]: 주행 플레이리스트 (격주 토요일)
  - Shorts [꿀팁 투척]: 짧은 꿀팁 (주 3~4회)

## 주제 아이디어 (없으면 자유 탐색)
{주제_아이디어 또는 "자유 발굴"}

## 리서치 목표
Tavily로 다음을 조사해줘:

1. 지금 유튜브에서 초보 운전 관련 뭐가 잘 되고 있나
   - 최근 1~3개월 내 높은 조회수/댓글 영상 패턴
   - 제목 키워드 트렌드

2. 네이버/구글 실시간 검색 트렌드
   - "운전 초보", "주차", "고속도로" 관련 자동완성 키워드
   - 사람들이 지금 뭘 궁금해하는지

3. 커뮤니티 최신 이슈
   - 보배드림, 클리앙, 네이버 카페, 에펨코리아 등
   - 초보 운전자들이 요즘 가장 많이 토로하는 어려움

4. {주제 아이디어가 있는 경우: 해당 주제의 기존 영상 경쟁 강도}
   - 유사 주제 기존 영상 수, 조회수 분포
   - 비어있는 틈새 각도

## 출력

### 트렌드 요약
(5줄 이내 핵심만)

### 검색 키워드 TOP 10
(지금 올라오는 것 위주로)

### 주제 후보 5개
| 주제 | 트랙 배정 후보 | 왜 지금인가 |
|------|--------------|------------|

### 경쟁 분석 (해당 시)
(기존 영상 공백/틈새)

TaskUpdate로 완료 표시해줘.
```

## Phase 3: script-architect + thumbnail-designer (병렬)

youtube-strategist 결과를 받아서 **단일 메시지에서 동시에** 실행.

### script-architect 프롬프트

```
너는 script-architect야. 유튜브 영상 스크립트를 쓰는 전문가야.
운전선생 : 0km 채널의 톤앤매너를 완벽하게 이해하고 써야 해.

## 영상 확정 정보
{youtube_strategist_result}

## 채널 톤앤매너 (반드시 준수)
- 친근하지만 전문적 — 마치 운전 잘 아는 친구가 설명하는 느낌
- 겁주지 않음 — "이거 모르면 사고 나요" X, "이렇게 하면 됩니다" O
- 원리 중심 — 단순 팁이 아니라 왜 그런지 설명
- 한국어, 구어체, 자연스럽게
- 시청자 호칭: "여러분" 또는 "초보 운전자 여러분"

## 스크립트 구조 (3단 필수)

### 1. 후크 (0~15초)
- 시청자가 멈추게 만드는 것
- 공포/불안/궁금증 중 하나를 자극
- 예: "고속도로에서 갑자기 끼어들기 당했을 때, 당신은 어떻게 하나요?"

### 2. 원리 (전체의 60~70%)
- WHY부터 시작 — "왜 이런 상황이 생기는가"
- 원리/메커니즘 설명 (그림, 예시, 비유 활용 지시 포함)
- 전문용어 사용 시 즉시 쉬운 말로 풀어서 설명

### 3. 실전 (전체의 20~30%)
- 오늘 바로 써먹을 수 있는 것
- 구체적 행동 지침 (1, 2, 3 순서)
- 마무리: 시청자에게 자신감 부여로 끝내기

## 스크립트 작성 규칙
- [B-ROLL: 설명] 형식으로 영상 편집 지시 포함
- [강조] 표시로 자막 강조 부분 표시
- 예상 읽기 시간 표시 (1분 = 약 150~160단어 기준)
- Track 3 (플레이리스트)인 경우: 스크립트 대신 선곡 리스트 + 각 곡 선정 이유 작성

## 출력

---
**영상 제목**: {확정 제목}
**트랙**: Track {N} [{트랙명}]
**예상 길이**: {N}분

---

### [후크] (0:00~0:15)
(스크립트)
[B-ROLL: ...]

### [원리] (0:15~N:NN)
(스크립트)
[B-ROLL: ...]
[강조: ...]

### [실전] (N:NN~끝)
(스크립트)
[B-ROLL: ...]

---
**편집 노트**: (편집자를 위한 전체 톤/스타일 한 줄)

TaskUpdate로 완료 표시해줘.
```

## 실행 규칙

1. **channel-bible.md 필수 참조** — youtube-strategist는 반드시 driving-teacher-ai-native 레포 루트의 `channel-bible.md`(이 스킬 파일 기준 `../../../channel-bible.md`)를 읽고 트랙 배정
2. **Phase 1 → Phase 2 순차 필수** — trend-hunter 완료 전 youtube-strategist 시작 금지
3. **Phase 3은 반드시 병렬** — script-architect와 thumbnail-designer를 단일 메시지에서 동시 실행
4. **Track 3 예외 처리** — 플레이리스트 트랙인 경우 script-architect는 스크립트 대신 선곡 리스트 작성
5. **Shorts 예외 처리** — Shorts인 경우 스크립트 길이 30~60초 기준으로 조정, 썸네일 → 커버 이미지로 전환
6. **TeamDelete 누락 금지** — 완료 후 반드시 팀 정리
