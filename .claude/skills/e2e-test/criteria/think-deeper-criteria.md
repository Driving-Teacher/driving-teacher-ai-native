# 평가 기준: think-deeper

## 채점 항목 (100점 만점)

### 1. 비개발자 접근성 (25점)
- 기술 용어 없이 진행되는가?
- 선택지가 직관적인가?
- "뭘 해야 하는지" 바로 이해할 수 있는가?

### 2. 상호작용 품질 (25점)
- AskUserQuestion 선택지가 사용자 답변에 맞게 동적 생성되는가?
- 5 Whys에서 "이게 근본 원인이다" 탈출구가 있는가?
- 사용자가 막히지 않고 자연스럽게 진행되는가?

### 3. 결과물 실용성 (25점)
- 최종 기획 문서가 실제로 쓸 수 있는 수준인가?
- Plan A/B/C가 구체적인가? (추상적 vs 실행 가능)
- 다음 액션이 명확한가?

### 4. 시간 효율 (25점)
- 4단계 전체가 15분 이내에 끝날 수 있는가?
- 불필요한 반복이나 장황한 설명이 없는가?
- 사용자가 "빨리 결론 줘" 하고 싶은 순간이 있는가?
